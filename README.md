# Mingming UGV 3D SLAM Point-Cloud Demo

Interactive browser demo for a simulated tracked UGV 3D SLAM map.

## Live demo

https://xuzhishui3223-rgb.github.io/mingming-ugv-slam-demo/

## Controls

- Drag with the left mouse button to rotate.
- Use the mouse wheel to zoom.
- Toggle automatic rotation and adjust point size from the control panel.
- Point colors represent height.

The included PLY cloud is generated from a MuJoCo educational simulation. No data is uploaded by the viewer after the static page has loaded.
